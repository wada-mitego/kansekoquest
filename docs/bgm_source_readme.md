## Claude Code への実装依頼
各画面の状態とBGMを1対1で対応させる。音楽はループで使用するが、MP3の境界に無音が入り得るため、実機でループ確認と必要な補正を行う。ページの初回タップ後に音声再生を許可する。問題出題中の音量はほかの画面より抑える。画面遷移時はBGMを停止/クロスフェードし二重再生を防ぐ。

※このセットはBGMのみ。正誤・能力アップ効果音、勝利ファンファーレは含まない。
