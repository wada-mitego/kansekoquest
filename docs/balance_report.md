# 戦闘バランス シミュレーション結果

条件: 5職業 × 正答率3水準(50/70/90%) × 育成3種 = 45条件、各条件 1000 試行（計 45000 通しプレイ）。
各試行は「10問回答 → 第1ボス挑戦 → 10問回答 → 第2ボス … → 第5ボス（3形態）」を各ボス初回挑戦のみで通す。1問ごとに正答率どおりに正誤を乱数で決め、正解した分だけ対応能力+1。ボス挑戦前の追加周回は含めない。
戦闘AIは、回復(スイジュク)・たたかう/ベンガリの選択・しゅうちゅう・ぼうぎょを使う。
