## 本編ボスの解放に必要な問題数

本編は5体構成（10問ごとに1体、50問でラスボス）。収録173問のうち異なる問題を50問以上初回回答すれば全ボスに到達できる（余裕 123問）。将来ボスを追加する場合は、問題の増加に合わせて `src/config.ts` の `MAIN_BOSS_IDS` に保管ボスのIDを足す。

公式の過去問（2022〜2026年度の第一次検定）は権利条件が未確認のため原文を収録していない。出典のない問題の水増しも禁止のため、出典を確認できた範囲（173問）で止めている。公式正答（2026年10月6日付の訂正を含む）と照合できる資料や、利用許諾のある問題の提供を受ければ、`src/data/questions.json` に追加するだけで反映される（`npm run validate` で検査）。
