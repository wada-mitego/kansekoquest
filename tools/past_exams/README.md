# 過去問(1級管工事 第一次検定)の取り込み

`src/data/past_questions.json` は、ユーザーが提供した公式PDF（全国建設研修センター公表の問題A/B・正答肢、令和4〜8年度）から生成しています。

## 再生成の手順
1. PDF（`R?_1kan_01_mondaiA/B.pdf`, `R?_1kan_01_kaitou.pdf`）を1つのフォルダに置く
2. 作業用フォルダで `npm i pdfjs-dist@4.10.38 @napi-rs/canvas` を実行し、このフォルダの `*.mjs` をそこへコピー
3. `node extract.mjs <PDFのフォルダ> txt` でテキスト抽出（pdfjs の日本語CMapを使う。pdftotext では文字が欠ける）
4. `node build_past.mjs txt <出力>/past_questions.json` → `src/data/past_questions.json` に置く
5. 目視確認用に `node render.mjs <pdf> <ページ> img` でページをPNG化できる

## 採用ルール（正確性優先）
- 正答は同年度の正答肢PDFの値のみ。問題文は原文のまま（ふりがなだけ除去）。解説は公式に無いので付けない。
- 図・表・空欄・組合せ形式の問題、文字化けが疑われる問題は採用しない。
- 令和4〜7年度のPDFは、数字や記号の一部が正しく抽出できない（0/1の取り違え、括弧の化け等）ため、数値・量の表現を含まない問題だけを採用。令和8年度は数字を含む問題も、ページ画像との照合で確認できたものを採用。
- 令和1〜3年度はスキャン画像（または正答がテキストでない）のため未取り込み。
